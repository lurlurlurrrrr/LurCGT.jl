# Public API

The pages in this section document LurCGT's supported public API. Non-exported
bindings may be used internally by Telum, but are not compatibility commitments
for direct users.

- [Symmetries](@ref): symmetry families, q-label operations, and dimensions.
- [Fusion and CGT transforms](@ref): fusion metadata and CGT basis transforms.
- [Local-space operators](@ref): symmetry-adapted local-space and IROP tools.
